# Фикстуры для retrieval/grounding smoke eval

`cases.json` содержит маленький детерминированный smoke-набор для кэпстоун-проекта.
Он не заменяет ручную проверку ответа, цитат, трейсa и health-отчёта по
конкретному `run_id`. Его задача уже: быстро проверить, что ретривал поднимает
ожидаемые raw-источники и не притворяется ответом там, где в корпусе нет
основания.

Он проверяет три вещи:

1. вопрос по планированию capacity находит правильные raw-источники;
2. вопрос по инциденту Aurora-17 находит правильный raw-источник;
3. вопрос вне корпуса не должен притворяться ответом с опорой на источники.
