# Проектный маршрут

В этом репозитории нет обязательных веток, специальных git-операций, скрытых
стартовых точек или внутренних кодовых меток. Студент проходит
кэпстоун-проект по одному простому маршруту:

1. установить зависимости;
2. запустить тесты;
3. выполнить локальный `kb-agent` на `fixtures/queries/project_query.json`;
4. прочитать `run_id`, сводку, ответ, пакет контекста, трейс и health;
5. выполнить `kb-eval`;
6. собрать короткий пакет сдачи по `docs/final-project.md`.

`starter_query.json` существует только как маленькая совместимая фикстура для
тестов. В обычном LMS-сценарии используйте `project_query.json`.

Опциональная «Живая Wiki» с proposal/diff — это расширение после базовой сдачи,
а не отдельная обязательная часть проекта.
