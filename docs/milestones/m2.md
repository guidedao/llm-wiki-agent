# Майлстоун M2: план и контекст

`M2` проверяет не весь финальный проект, а первый читаемый путь запуска:
вопрос -> план -> пакет контекста -> ответ -> source-map -> источники.

## Что запустить

```bash
uv sync --frozen --extra dev
uv run pytest
uv run kb-agent --query-fixture fixtures/queries/project_query.json --vault-root vault
```

## Что открыть по `run_id`

1. `vault/outputs/<run_id>-summary.md` — короткая карта запуска.
2. `vault/outputs/<run_id>.md` — итоговый ответ.
3. `artifacts/source-map/<run_id>.json` — raw-источники, которые поддерживают ответ.
4. `artifacts/plans/<run_id>.json` — план и focus terms.
5. `artifacts/context/<run_id>.json` — пакет, который харнес передал модели.
6. `artifacts/traces/<run_id>.jsonl` — события запуска.

## Готово, когда

1. тесты проходят;
2. `kb-agent` создаёт `run_id`;
3. summary связывает ответ, source-map, context и trace;
4. один тезис ответа можно пройти до wiki-страницы и raw-источника;
5. вы можете объяснить, что `vault/wiki/` — устойчивый знаниевый слой, а
   `artifacts/` — след одного запуска.

Если что-то не сходится, откройте `docs/student-help.md`.
